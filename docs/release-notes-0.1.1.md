# Metronome 0.1.1

Metronome is now part of the **HACS default list**: search for **Metronome** in HACS to install it. Adding the custom repository still works as a fallback.

## Changed
- README install section: search in HACS first, custom repository steps as a fallback; badge shows "HACS Default".

No code changes since 0.1.0.

**Update:** HACS → Metronome → Update, then reload the app or browser. The card resource gets its new version number at the next Home Assistant restart.

Full details in the [CHANGELOG](https://github.com/ak111pro/ha-metronome/blob/main/CHANGELOG.md).
